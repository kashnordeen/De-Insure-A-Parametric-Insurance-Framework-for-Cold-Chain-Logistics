# AWS IoT Certificates Directory

Place your 3 downloaded AWS IoT certificate files here:
1. `AmazonRootCA1.pem` (AWS Root CA 1)
2. `certificate.pem.crt` (Device Certificate)
3. `private.pem.key` (Device Private Key)

These files will be automatically loaded by `oracle_aws.py` to establish a TLS 1.2 secure connection to AWS IoT Core (`avlxhxuyvpb4m-ats.iot.eu-north-1.amazonaws.com`).
